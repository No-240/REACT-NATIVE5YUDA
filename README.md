## CARA MENJALANKAN PROJEK
1. Pastikan Node.js dan Expo CLI sudah terpasang di komputer atau di Smartphone.
2. Buka terminal dan arahkan ke folder project dengan perintah "bash".
3. Setelah masuk ke folder langsung beri perintah "npx expo start -c".
4. Jika melihat kode QR atau link sambungkan dengan Expo Go di smartphone.
